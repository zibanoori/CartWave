# 🛍️ CartWave - Modern E-Commerce Shop Interface

A clean, responsive, and modern e-commerce shop interface designed with a focus on user experience (UX) and visual aesthetics. This project showcases advanced CSS techniques, smooth animations, and a mobile-first approach.

## 🚀 Features

- **Modern Product Grid:** Elegant card designs with hover effects, floating action buttons, and consistent image sizing.
- **Advanced Filtering & Sorting:** Custom-styled dropdowns for sorting products by price, popularity, and new arrivals.
- **Responsive Design:** Fully optimized for mobile, tablet, and desktop devices using Bootstrap 5 grid system.
- **Interactive Pagination:** Clean and accessible page navigation with custom styling.
- **Empty State Handling:** User-friendly feedback when no products match the search or filter criteria.
- **Dark/Light Mode Ready:** Built with CSS variables to support seamless theme switching.

## 🛠️ Tech Stack

- **HTML5:** Semantic markup for better accessibility and SEO.
- **CSS3:** Advanced styling including Flexbox, Grid, Custom Properties (Variables), and Cubic-bezier animations.
- **Bootstrap 5.3:** For rapid layout development and responsive components.
- **JavaScript (Vanilla):** For interactive elements like pagination logic and theme toggling.
- **Bootstrap Icons:** For lightweight and scalable vector icons.

## 🎨 Design Highlights

- **Smooth Animations:** Utilizing `cubic-bezier(0.22, 1, 0.36, 1)` for natural and premium-feeling transitions.
- **Minimalist Aesthetic:** Focus on whitespace, clean typography, and subtle shadows instead of heavy borders.
- **Accessibility:** ARIA labels and semantic tags used throughout to ensure inclusivity.
